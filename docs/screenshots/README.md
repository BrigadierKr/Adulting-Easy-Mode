# 📸 Скриншоти проєкту «Сам собі мама» (v2.0)

У цій директорії зберігаються скриншоти інтерфейсу, що демонструють ключову функціональність PWA-застосунку.

### 🖼 Перелік ключових екранів:

1. **`01_kitchen_youtube_bridge.png` — Кулінарний модуль + YouTube-місток**
   - Швидкі рецепти (яєчня, макарони, пельмені)
   - Вбудовані інтерактивні таймери варіння
   - Кнопка «🎬 Дивитись відео» з прямим безпечним пошуковим переходом на YouTube
   - SOS-інструкція «Підгорає їжа!»

2. **`02_laundry_3d_flip_cards.png` — Декодер значків прання (3D Flip-Cards)**
   - Інтерактивні картки із плавною CSS/Motion 3D-анімацією перевертання
   - Категорії: прання, сушіння, прасування, відбілювання, хімчистка
   - Розблокування досягнення «Залізна людина» при взаємодії

3. **`03_meters_reading_chart.png` — Трекер лічильників комуналки + Графік**
   - SVG-графік динаміки споживання електроенергії та води за місяцями
   - Розрахунок різниці (дельта споживання)
   - Кнопка швидкого копіювання сформованого тексту показників для передачі в ОСББ/ЖЕК

4. **`04_budget_donut_visualizer.png` — Калькулятор бюджету 60/25/15 + Donut Chart**
   - Інтерактивна SVG діаграма-бублик розподілу доходу
   - Формула: 60% обов'язкові витрати, 25% радість та бажання, 15% заначка/резерв
   - Попередження при виході за межі бюджету з порадами мами

5. **`05_autumn_drop_heating_and_repair.png` — Осінній дроп v2.0 «Опалювальний сезон & Дрібний ремонт»**
   - Банер сезонного оновлення з лічильником виконання карток
   - Акордеон перевірки опалення та спуску повітря (кран Маєвського)
   - Блок «Дрібний ремонт» (дюбелі, ущільнювачі D-профіль, правило WD-40)
   - Гібридне правило відеобезпеки (червоні бейджики ⚠️ для небезпечних робіт)
   - Кнопки «✓ Зроблено» з каскадним відкриттям досягнень ach-21..ach-26
