## 📖 Про проєкт & Місія

**«Adulting: Easy Mode»** — це незамінний кишеньковий помічник для студентів, молоді та всіх, хто вперше починає жити окремо від батьків. Додаток перетворює щоденну побутову рутину на зрозумілу грифіковану гру, допомагаючи вирішувати поширені проблеми без паніки:
- Як зварити ідеальну гречку або макарони і переглянути відео-інструкцію у 1 клік;
- Що робити, коли палає олія на пательні чи смердить із сифона;
- Як прочитати й передати показники лічильників і проаналізувати витрати на наочному інтерактивному графіку;
- Як розрахувати особистий бюджет за формулою виживання (60/25/15) та побачити структуру витрат у Donut-чарті;
- Як розшифрувати незрозумілі символи прання за допомогою інтерактивних 3D-фліп карток.

## ✨ Ключові можливості (Модулі)

### 🍳 1. Кухня (Рецепти-п'ятихвилинки & Таймер)
- **Базові страви:** Гречка, рис, яйця, макарони, вівсянка — покрокові алгоритми з пропорціями та авторським гумором.
- **🎬 YouTube-Міст:** Пряма кнопка перегляду відеорецепту на YouTube для кожної страви.
- **Кухонний таймер:** Інтерактивний відлік часу для варіння яєць та каш із фоновим сповіщенням.
- **SOS-Поради:** Покрокові інструкції, якщо збігло молоко, згоріла каша чи спалахнула олія.

### 📊 2. Комуналка & Бюджет
- **Трекер лічильників:** Збереження показників (електрика, гаряча/холодна вода, газ) з копіюванням результату в 1 тап.
- **📊 SVG Bar Chart:** Наочний графік місячного споживання електроенергії та води для порівняння динаміки між місяцями.
- **🍩 SVG Donut Budget Chart:** Інтерактивна діаграма розподілу витрат із вибором категорій, розрахунком відсотків та сум.
- **🔔 Автоматичні нагадування (Web Notification API):** Push-сповіщення 1–5 числа кожного місяця.

### 🚨 3. Швидка допомога (SOS & Прання)
- **SOS-Картки дій:** Алгоритми при протіканні крана, вибиванні пробок, розморожуванні холодильника.
- **🎬 YouTube SOS-Відео:** Кнопка перегляду наочних відеофіксів на YouTube.
- **🔄 3D Flip Laundry Symbols:** Інтерактивна сітка символів прання на ярликах одягу. Перевертай картку 3D-анімацією, щоб дізнатися розшифровку та «пораду від мами».

### 🧹 4. Прибирання & Чеклисти
- **7-хвилинні ритми:** Щоденне швидке прибирання та щотижневі чек-листи.
- **Прогрес-бари:** Відстеження відсотка виконаних завдань із можливістю скидання в 1 клік.

### 🏆 5. Досягнення & Квізи
- **Гейміфікація:** 20 ігрових досягнень («Не спалив кухню», «Залізна людина», «Майстер бюджету» тощо).
- **Квізи:** Інтерактивні тести для перевірки побутової ерудиції.

## 🌐 Мультимовність & Теми

- **3 Мови:** Українська (UA), English (EN), Русский (RU) з миттєвим перемиканням без перезавантаження.
- **Теми оформлення:** Системна (Auto), Світла (Light) та Темна (Dark Mode) у стилі Neo-Brutalism (високий контраст, чіткі межі, яскраві акценти).

---

## 📱 PWA (Progressive Web App)

- **Offline-First:** Працює без інтернету завдяки Service Worker (`sw.js`).
- **PNG-Іконки:** Повноцінний набір PNG-іконок (192x192, 512x512) для швидкого додавання на домашній екран Android, iOS або робочий стіл ПК.
- **PWA Install Prompt:** Вбудована кнопка інсталяції додатка.

---

## 🛠 Технологічний стек

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Lucide React (vector icons)
- **Animations:** Motion (`motion/react`)
- **Visualizations:** Pure SVG Charts (Custom Bar & Donut Charts)
- **PWA & Native APIs:** Service Worker API, Web Notification API, Web App Manifest
- **State & Storage:** React Context API + Client LocalStorage

## 💻 Як запустити проєкт локально

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-username/Adulting-Easy-Mode.git
   cd Adulting-Easy-Mode
   ```

2. **Встановіть залежності:**
   ```bash
   npm install
   ```

3. **Запустіть dev-сервер:**
   ```bash
   npm run dev
   ```
   Застосунок відкриється за адресою `http://localhost:3000`.

4. **Збірка для продакшену:**
   ```bash
   npm run build
   ```
