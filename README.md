# 🏠 Сам собі мама (Adulting: Easy Mode / Мама не приедет)

> **Навчальний PWA-застосунок для самостійного життя з гумором та іронією.**

![Сам собі мама](public/icon-512.png)

Веб-застосунок створений для молоді та студентів, які вперше починають жити окремо від батьків. Він допомагає вирішувати щоденні побутові проблеми без паніки: від того, як зварити ідеальну гречку чи випрати кросівки, до передачі показників лічильників та планування щомісячного бюджету.

---

## ✨ Основні можливості

- 🍳 **Кухня (Рецепти-п'ятихвилинки):**
  - Покрокові рецепти базових страв (гречка, рис, яйця, макарони, вівсянка) з пропорціями та гумористичними порадами.
  - Вбудований кухонний таймер.
  - SOS-інструкції на випадок, якщо підгорає їжа чи палає олія.

- 📊 **Комуналка & Бюджет:**
  - Зручний трекер та калькулятор лічильників (електрика, вода, газ) з можливістю копіювання показників у 1 клік.
  - **Автоматичні push-сповіщення (Web Notification API):** нагадування про передачу показників з 1 по 5 число кожного місяця.
  - Калькулятор бюджету за формулою виживання (60% потреби / 25% бажання / 15% резерв).

- 🧹 **Прибирання:**
  - Інтерактивні чеклисти для щоденного (7-хвилинка) та щотижневого прибирання з можливістю скидання задач.

- 🚨 **Швидка допомога (SOS & Прання):**
  - Покрокові алгоритми дій: вибило пробки, смердить із сифона, як випрати кросівки, як розморозити холодильник.
  - Інтерактивна розшифровка всіх значків на ярликах одягу (прання, відбілювання, сушка, прасування, хімчистка).

- 🏆 **Досягнення & Квізи:**
  - 20 ігрових досягнень (гейміфікація побуту) із системою розблокування за виконання дій у додатку.
  - Навчальні квізи для перевірки знань у кожному модулі.

- 🌐 **Мультимовність & Теми:**
  - Повна підтримка 3 мов: **Українська (UA)**, **English (EN)**, **Украинский/Русский (RU)**.
  - Світла та Темна теми (Dark Mode) + розробка у стилістики Neo-Brutalism.

- 📱 **PWA (Progressive Web App):**
  - Повноцінна підтримка оффлайн-роботи через Service Worker (`sw.js`).
  - PNG-іконки 192x192 та 512x512 для встановлення як додаток на Android, iOS та ПК.

## 🛠 Технологічний стек

- **Frontend:** React 18, TypeScript, Vite
- **Стилізація:** Tailwind CSS v4, Lucide React (іконки)
- **Анімації:** Motion (`motion/react`)
- **PWA & Сповіщення:** Service Worker API, Web Notification API, Web App Manifest
- **Збереження стану:** Client-side LocalStorage

## 💻 Як запустити локально

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-username/Adulting-Easy-Mode.git
   cd Adulting-Easy-Mode
   ```

2. **Встановіть залежності:**
   ```bash
   npm install
   ```

3. **Запустіть dev-сервер:**
   ```bash
   npm run dev
   ```
   Додаток буде доступний за адресою `http://localhost:3000`.

4. **Збірка для продакшену:**
   ```bash
   npm run build
   ```
