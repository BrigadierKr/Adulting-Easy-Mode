# 🏠 Сам собі мама · Adulting: Easy Mode · Мама не приедет

Гумористичний навчальний PWA-застосунок для молоді, що почала жити окремо: студентів, випускників шкіл і всіх, хто щойно виїхав від батьків. Вчить базових побутових навичок через короткі картки, чеклісти, квізи та досягнення — без повчань, із гумором.

🔗 **Demo:** https://service-7336.ai.studio
📦 **Поточна версія:** v2.1 «Гейміфікація» (жовтень 2026)

## 💡 Ідея

Проєкт виріс із реальної історії: син автора переїхав жити окремо й виявив, що «хата сама працює» лише тоді, коли нею хтось займається. Так з'явилась ідея перетворити побутове виживання на дружній квест із сезонними оновленнями.

## 📊 Дослідження (Google Trends, Україна, 12 міс)

Пріоритети модулів обрані на основі даних, а не інтуїції:

| Запит | Сигнал | Рішення |
|---|---|---|
| «як приготувати» | 60–100, №1 в усіх 24 областях | 🍳 «Кухня» — головний модуль |
| «показники лічильника» | щомісячні піки 75–100 по всій країні | 💰 трекер показників + нагадування |
| «як прибрати» | стабільні ~20–25 | 🧹 модуль «Прибирання» |
| «бюджет на місяць» | Breakout-тренд | 💸 калькулятор бюджету |
| «вибило пробки», «смердить з сифона» | рідкісні, але панічні | 🚨 «Швидка допомога» |
| осінні піки: «не гріють батареї», «кран Маєвського» | сезонний стрибок | 🍂 сезонний дроп v2.0 |

**Ключовий інсайт:** кулінарні how-to частіше шукають на **YouTube**, ніж у Google → кожна безпечна картка має кнопку «🎬 Дивитись відео».

## ✨ Можливості

- 🍳 **Кухня** — рецепти-п'ятихвилинки, таймер приготування, SOS «підгорає їжа», квіз
- 💰 **Комуналка** — трекер показників із графіком витрат, нагадування 1–5 числа, калькулятор бюджету з донат-діаграмою (60/25/15), сезонний блок опалення
- 🧹 **Прибирання** — щоденні/щотижневі чеклісти з прогрес-барами
- 🚨 **Швидка допомога** — SOS-картки «Без паніки», flip-декодер значків прання, блок «Дрібний ремонт», глобальний пошук
- 🍂 **Сезонні дропи** — банер із трекером проходження X/10 та кнопкою «✓ Зроблено»
- 🏆 **28 досягнень** з toast-сповіщеннями, каскадним розблокуванням та стрік-марафонами
- 🎮 **Гейміфікація v2.1:** активні стріки (🔥), система рівнів (Школяр → Легенда ЖК), XP за корисні дії, інтерактивна Wordle-сітка активності за останні 7 днів із шерингом
- 🌐 **3 мови:** UA / EN / RU · 🌗 темна тема
- 📱 **PWA:** офлайн, інсталяція на телефон · 💾 усі дані локально (localStorage)

## 🍂 Система сезонних дропів

Ритм оновлень: **4 сезонні дропи на рік** + щомісячні мікро-оновлення (поради, квізи) + **квартальний Google Trends-чек** для вибору наступної теми.

| Версія | Дата | Зміст |
|---|---|---|
| v1.0 | серпень 2026 | MVP: 5 модулів, 3 мови, PWA, 20 досягнень |
| v2.0 | жовтень 2026 | «Осінній дроп»: опалювальний сезон без шоку + дрібний ремонт — 12 нових карток, 6 досягнень, трекер дропу |
| v2.1 | жовтень 2026 | «Гейміфікація»: щоденні стріки, 4 рівні, нарахування XP, Wordle-сітка шерингу тижня, ach-27 та ach-28 |
| v2.2 | грудень 2026 (план) | «Новий рік без ДСНС»: гірлянди, подовжувачі, святкова духовка |


## 🎬 Гібридне правило відеобезпеки

Кожна картка має прапорець `videoSafe`:

- **`true`** → кнопка «🎬 Дивитись відео» (YouTube-місток; у перспективі — AI-відеоінструкції)
- **`false`** (електрика, газ, вода під тиском, свердління біля проводки) → лише текст + піктограми, перевірені людиною, + бейдж «⚠️ Не знімати на відео — небезпечно»

**Чому це важливо:** візоконтент (зокрема згенерований ШІ) не має права вчити небезпечних дій. Текстова інструкція лишається джерелом правди, а відео — лише допоміжним форматом для безпечних тем.

## 🛠 Стек

React 19 · TypeScript · Vite 6 · Tailwind CSS 4 · Motion · Lucide React · Service Worker (PWA)

## 🚀 Запуск

```bash
npm install
npm run dev     # локально на :3000
npm run build   # production-збірка
npm run lint    # tsc --noEmit
```

## 📁 Структура

```
src/
├── components/   # модулі UI (Kitchen, Utilities, Cleaning, QuickFix…)
├── context/      # AppContext — стан + localStorage + PWA install
├── data/         # content.ts — ВЕСЬ контент трьома мовами (i18n)
└── types.ts      # інтерфейси контенту, SeasonBlock, videoSafe
```
